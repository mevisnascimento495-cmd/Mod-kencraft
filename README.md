# KenCraft

Mod KenCraft para Minecraft 1.21.1 + NeoForge 21.1.248.

## Alpha atual

- Sistema de raça: Rinka / Humano.
- Status persistente: raça, Jio e Jio máximo.
- HUD de status no canto superior esquerdo.
- NPCs básicos protegidos.

## NPCs

Dentro do jogo, use:

`/kencraft npcs`

O comando cria dois NPCs simples perto do jogador:
- NPC • Onoki
- NPC • Mestre Jio

Eles são aldeões parados, invulneráveis e persistentes. Esta é a base mínima para evoluirmos depois para diálogos, missões e modelos próprios.
